Introduction

Welcome to the API WORLD developer documentation. All of our APIs follow RESTful conventions, return JSON, and are secured with API keys.

Base URL for all endpoints:

https://api.apiworld.dev/v1/

Authentication

Every request must include your API key in the X-API-Key header:

curl -H "X-API-Key: YOUR_API_KEY" \
  https://api.apiworld.dev/v1/weather?city=London

You receive your unique key via email immediately after a successful PayPal payment. Keys are scoped to the products you purchased.

Rate Limits

Default rate limits by plan tier:

  • Starter — 1,000 requests / day
  • Growth — 10,000 requests / day
  • Scale — 100,000 requests / day

Rate limit headers are returned on every response:

X-RateLimit-Limit: 10000
X-RateLimit-Remaining: 9842
X-RateLimit-Reset: 1694784000

Error Handling

We use standard HTTP status codes. Error responses always include a machine-readable code and human-readable message:

{
  "error": {
    "code": "invalid_api_key",
    "message": "The provided API key is invalid or has been revoked."
  }
}
  • 400 — Bad Request
  • 401 — Unauthorized (missing/invalid key)
  • 403 — Forbidden (key lacks permission for this endpoint)
  • 429 — Too Many Requests
  • 500 — Internal Server Error

Quickstart

1. Purchase an API from the Marketplace and complete PayPal checkout.

2. Check your email for the API key (arrives within seconds).

3. Make your first request:

const response = await fetch(
  'https://api.apiworld.dev/v1/weather?city=Tokyo',
  {
    headers: {
      'X-API-Key': process.env.APIWORLD_KEY
    }
  }
);
const data = await response.json();
console.log(data);

Pricing & Plans

All products are billed monthly. Prices shown on the marketplace are the base monthly fee and include the Starter rate limit. You can upgrade rate limits at any time from your dashboard (coming soon).

Payments are processed exclusively through PayPal. We never store card details.

Webhooks

Selected APIs (MarketData, CryptoTracker, NewsStream) support real-time webhooks. Configure your endpoint URL in the dashboard and we will POST signed events when relevant data changes.
